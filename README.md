# 简易输入法工具栏（自研 Xposed 模块）

一个**自己写的**输入法工具栏模块：在键盘上方加一条可自定义的按钮栏。
参考了 `AI超级工具栏 5.0.5` 的实现思路（把 View 挂到输入法窗口上、配置用远程偏好读），
但**代码全部重写**，并且去掉了原版所有高风险的部分。

适用：Android 8.0+（minSdk 27），需要 **LSPosed / libxposed API 101+** 的 Xposed 环境。

---

## 与原版的区别（为什么更放心）

| 项目 | 原版 AI超级工具栏 | 本模块 |
|---|---|---|
| 联网 | 必须联网登录；账号密码走**明文 HTTP** 上传到作者自建服务器 | **没有 INTERNET 权限**，一个字节都不发 |
| 授权 | 账号 + 设备绑定 + 服务端可远程关掉 | 无授权，装完就能用 |
| 剪贴板 | 记录剪贴板历史，另有一个**导出且不校验调用方**的 Provider | 不记录、不落盘 |
| root / shell | 有通用的 `su` 执行通道 + 一堆内置 shell 动作 | 只有用户自己配的「ADB 命令」动作（`adb`，需要 root，默认按钮里没有） |
| 对外接口 | 3 个导出组件（广播/服务/Provider） | 只有 2 个必需的：libxposed 的 `XposedProvider` + 只读的配置 Provider |
| 权限 | 悬浮窗、所有文件、查询所有应用、联网… | **零权限** |
| 代码 | R8 混淆 + 8MB dex + 13KB 原生库 | 6 个 Java 文件，无混淆、无原生库 |

> 注意：任何 hook 输入法的模块，理论上都能看到你输入的内容。**本模块自己不做任何采集**，
> 但你还是应该只在自己可控的设备上用，并且按需勾选作用域（只勾你日常用的那一个输入法）。

## 一、快速开始（全程不用在本机装 Android 环境）

### 1. 把代码推到 GitHub

在 GitHub 网页上新建一个空仓库（例如 `imebar`，**不要**勾选 Add README / .gitignore），
然后在本机这个目录下执行（把 `你的用户名` 换成你的 GitHub 用户名）：

```bash
git init
git add .
git commit -m "简易输入法工具栏 v0.1.0"
git branch -M main
git remote add origin https://github.com/你的用户名/imebar.git
git push -u origin main
```

### 2. 等云端自动编译

推送完成后，打开仓库的 **Actions** 标签页：

* 会自动跑一个叫 `build-apk` 的任务（大约 2~4 分钟，第一次要下载依赖会慢一点）；
* 跑完后点进这次运行，页面底部 **Artifacts** 里下载 `imebar-apk`，里面有两个 APK：
  * `app-debug.apk` —— 调试包
  * `app-release.apk` —— 用 debug 签名打的正式包（体积略小，用它就行）

如果想手动重跑：Actions → 左侧 `build-apk` → 右侧 `Run workflow`。

### 3. 安装并启用

1. 把 APK 传到手机安装（会提示"未知来源"，允许即可）；
2. 打开 **LSPosed 管理器** → 模块 → 找到「简易输入法工具栏」→ **启用**；
3. 点 **作用域** → 只勾选你实际在用的输入法（例如"豆包输入法""搜狗输入法""Gboard"），
   然后 **重启输入法进程**（最省事的办法：切一次输入法，或者重启手机）。
   模块已经在 `META-INF/xposed/scope.list` 里推荐了 17 款常见输入法，**豆包输入法 `com.bytedance.android.doubaoime` 排在第一位**；
4. 打开本模块的桌面图标（设置页）→ 按需调整 → 保存。**保存后即时生效**，不用切输入法。

## 二、界面

**位置：键盘底部。** 工具栏贴在输入法窗口的下边缘，也就是**那排按键的下面**（和 AI超级工具栏 一样的位置）。
它是往输入法窗口里加了一条 View，窗口自动长高、键盘整体上移，所以不会盖住按键，也不占屏幕上方的空间。

**默认形态：一排透明文字。** 整条栏背景默认全透明（`#00000000`），按钮是纯文字、等宽铺满整行，不画图标、不加底、不加边框——就是"底部只有字"。

**点击行为：** 普通按钮直接执行；带菜单的按钮会在**该按钮正上方**弹出一张白色圆角卡片（紧凑条目、黑字、条目间有细分隔线），水平方向对齐按钮、靠边时自动夹回窗口内；点卡片外面收起，再点同一个按钮也收起。

### 可调参数（设置页）

| 参数 | 说明 | 默认 |
|---|---|---|
| 启用工具栏 | 总开关 | 开 |
| 底部距离 | 工具栏距键盘底边的高度 | 0 dp |
| 左右边距 | 工具栏两侧与屏幕边缘的距离 | 50 dp |
| 文字大小 | 文字按钮的字号 | 10 dp（可调 5~24） |
| 显示透明度 | 整条栏的不透明度 | 65 % |
| 文字颜色 / 整条栏背景色 | 配色 | `#202124` / 全透明 |

坐标是照着 AI超级工具栏 的「显示设置」定的。以下三项**固定，不提供选择**（按使用习惯定死更省心）：

* 位置：**键盘底部**（那排按键的下面）
* 按钮样式：**纯文字**（无底色、无边框）
* 排列方式：**均分铺满**（按钮等宽横向铺开）

原版还有「图标大小」「胶囊样式」这类项，本模块只做纯文字按钮，所以都没有；按钮之间的间距固定 8dp，也不做成可调项。
设置页是 **Material Design 3** 风格，而且是**零依赖**手写的（只用系统控件 + 代码自绘，
没有引入 AndroidX / Material Components，APK 还是几十 KB）：

* 固定蓝色系色板，基于 `#0B57D0`（主按钮、开关、滑条用它），颜色统一在 `res/values/colors.xml`
* 每节是一张卡片：12dp 圆角 + 1dp 阴影，卡片之间、页面左右都留间隙
* 「启用工具栏」是 MD3 开关（Switch），不是老式复选框
* 按钮是胶囊形（28dp 圆角）且**按下有涟漪**；主按钮主色底白字，次按钮浅蓝底深蓝字
* 输入框是 MD3 outlined：常态 1dp 灰描边，聚焦变 2dp 主色描边
* **改完点「保存」才生效**（手动保存），「恢复默认」会填好默认值并立即保存

键盘上弹出的菜单卡片也打磨过：**锚定在被点按钮的正上方**（手动 measure 算坐标，弹出即是最终位置，
不闪帧；上方放不下会改到按钮下方，拿不到坐标就退回居中），白色底 + 12dp 圆角 + 3dp 阴影，
条目紧凑（14sp 文字、约 36dp 高）且文字固定深色
（不再跟随工具栏的文字颜色——那个颜色是给透明底配的，放白卡片上可能看不清）。

### 设置改动怎么生效

libxposed 的远程配置是**内存快照**，创建之后不会自己更新，LSPosed 侧还可能把对象缓存起来，
所以"改了设置再重读一遍"这条路并不可靠。本模块改成**把数值本身送过去**：

1. **保存时推送数值**：设置页保存后，把整份配置（底部距离、左右边距、文字大小、透明度、颜色、按钮）
   打包进广播一起发出去；输入法进程收到后**直接用这份数值**重建工具栏——不读文件、不读远程偏好，所以必定是新值；
2. **进程重启后兜底**：如果输入法进程之前被系统杀掉过，本次进程内还没收到推送，就用启动时读到的模块配置先建一次。

结论：改设置 → 保存 → 立刻生效；重启手机 → 也还是你上次保存的值。

如果你改了设置却完全没反应，用 `adb logcat -s ImeBar` 看有没有 `工具栏已挂载(...)` 这行日志，
日志里会打印当前实际生效的底部距离/左右边距/字号/透明度，方便对照。

## 三、配置说明

按钮配置是 **JSON 数组**：一个元素一个按钮，字段是 `label`（显示文字）、`action`（动作）、
`arg`（参数，可省）、`menu`（只有菜单按钮用）。整行以 `//` 开头是注释。

> 从 0.15.0 起只认 JSON。旧的 `显示文字|动作|参数` 竖线格式**不再支持**：升级后如果存的还是旧格式，
> 会自动改用默认按钮，并且设置页里直接显示默认 JSON，重新编辑保存即可。

设置页默认给的是：

```
[
  {"label": "复制", "action": "copy"},
  {"label": "粘贴", "action": "paste"},
  {"label": "全选", "action": "select_all"},
  {"label": "收起键盘", "action": "hide"},
  {"label": "复制日志", "action": "log"}
  // {"label": "截屏", "action": "adb", "arg": "screencap -p /sdcard/imebar.png"}
]
```

最后一行是注释（`//` 开头会被忽略），要用的时候把 `//` 去掉即可。
`label` 不写就用 `action` 顶上；认不出来的字段会被忽略，所以可以放心往后加东西。

### 可用动作

| 动作 | 作用 | 需要参数 |
|---|---|---|
| `copy` | 复制选中内容 | 无 |
| `cut` | 剪切选中内容 | 无 |
| `paste` | 粘贴 | 无 |
| `select_all` | 全选当前输入框 | 无 |
| `clear` | 清空当前输入框 | 无 |
| `enter` | 回车 / 发送 | 无 |
| `delete` | 退格 | 无 |
| `left` / `right` | 光标左移 / 右移 | 无 |
| `hide` | 收起键盘 | 无 |
| `text` | 插入一段固定文字 | `arg` 写文字 |
| `app` | 打开某个 App | `arg` 写包名 |
| `url` | 用浏览器打开链接 | `arg` 写网址 |
| `adb` | 跑一条 shell 命令（**需要 root**） | `arg` 写命令 |
| `log` | 把输入法进程的运行日志复制到剪贴板 | 无 |

例子：

```
[
  {"label": "我的地址", "action": "text", "arg": "广东省深圳市南山区xx路1号"},
  {"label": "打开微信", "action": "app", "arg": "com.tencent.mm"},
  {"label": "搜索", "action": "url", "arg": "https://www.bing.com"},
  {"label": "截屏", "action": "adb", "arg": "screencap -p /sdcard/imebar.png"}
]
```

配色项支持 `#AARRGGBB` 写法（例如 `#80202124` 是半透明深灰）。

---

### 菜单按钮（弹出卡片菜单）

`action` 写 `menu`，子项放在 `menu` 数组里，子项结构和普通按钮一样：

```
[
  {"label": "更多", "action": "menu", "menu": [
    {"label": "复制", "action": "copy"},
    {"label": "清空", "action": "clear"},
    {"label": "截屏", "action": "adb", "arg": "screencap -p /sdcard/imebar.png"}
  ]}
]
```

效果就是点一下「更多」，**在那个按钮正上方**弹出一张白色圆角卡片，条目之间有分隔线；点空白处收起。

---

### ADB 命令（需要 root）

设置页里没有单独的调试界面 —— 直接写进「按钮」那一栏就行：

```
截屏|adb|screencap -p /sdcard/imebar.png
返回|adb|input keyevent 4
关掉微信|adb|am force-stop com.tencent.mm
```

命令跑在后台线程里（最多等 10 秒，不会卡住输入法），结果写进运行日志，
并用一句 Toast 告诉你成功还是失败。

几点说明：

* **需要 root**（走 `su -c`）。没有 su 时会自动按普通 App 身份再试一次，结果会明确告诉你；
* root 被拒（Magisk 授权弹窗点了拒绝）时会提示"root 被拒绝了"，命令不会静默失败；
* 命令的文本就存在本机偏好里，别把设备借给别人乱翻；
* 这条通道是为了让你自由组合动作，默认按钮里不含它，只有你自己写了才存在。

## 四、出问题怎么办

### 工具栏没出现

1. 先确认 LSPosed 里模块**已启用**、作用域**勾了当前输入法**，并且 **重启过输入法进程**；
2. 用电脑连手机看日志（最有用的一招）：

```bash
adb logcat -c && adb logcat -s ImeBar
```

然后切出键盘，看有没有出现：

```
I ImeBar: 模块已加载, 进程=com.xxx.ime
I ImeBar: 已 hook android.inputmethodservice.InputMethodService#onStartInputView
I ImeBar: 工具栏已挂载, 按钮数=7
```

* 只有第一行、没有后面两行 → 作用域没勾对，或者输入法进程没重启；
* 有"工具栏已挂载"但屏幕上看不到 → 换个输入法试试（个别输入法把窗口高度写死了，见下面"已知限制"）。

### 按钮点了没反应

有些输入框（尤其是密码框、某些 App 自绘的输入框）不支持 `copy/paste/select_all`，
这时日志里会出现"这个输入框不支持"，属于正常现象。`text`（插入固定文字）几乎都能用。

### 怎么打开设置页

从**桌面图标**打开「简易输入法工具栏」就行。

工具栏上的「打开设置」按钮在 0.10.0 里已经删掉了：从输入法进程启动别的 App 的 Activity
属于"后台启动"，国产 ROM（小米/MIUI/HyperOS 的「后台弹出界面」等）会把它静默拦掉，
所以那个按钮在不少机器上本来就打不开，留着反而误导。

## 五、已知限制与后续可做

**当前版本（v0.10.0）**

* 只改"键盘上方那一条"，不碰各家输入法自己的界面；
* 个别输入法窗口高度固定，工具栏可能被裁掉（换输入法或告诉我，我改成悬浮窗方案）。
* 走的是**固定签名**，版本之间可以直接覆盖安装。

**想让我继续加的功能**（说要哪个就行）

1. **图形化按钮编辑**：不用手写 `文字|动作|参数`，改成列表 + 下拉选动作；
2. **App 选择器**：点一下列出已安装应用让你选，自动填包名；
3. **多页 / 长按菜单**：一页放不下就翻页、长按出二级菜单；
4. **常用语面板**：键盘上方弹出你自己的常用语列表（纯本地，不记录剪贴板历史）；
5. **AI 调用**：自己填 API Key 做润色/翻译（这样就涉及联网，会单独加 INTERNET 权限并说明）。

## 六、技术备注

* 依赖：官方 libxposed 的三个 jar 放在 `app/libs/`（从官方 AAR 里抽出的 classes.jar，见该目录的 README.txt）：
  `api` 是 `compileOnly`（运行时由 LSPosed 框架提供，绝不能打进 APK），
  `service`+`interface` 是 `implementation`（提供 `XposedProvider`，远程配置要用）。
  这样绕开了官方 AAR 元数据里 `minCompileSdk=37` 的限制，用 AGP 8.7.3 + compileSdk 35 即可编译；
* 模块声明：`app/src/main/resources/META-INF/xposed/module.prop`（`minApiVersion=101`）+
  `java_init.list`（入口类 `com.local.imebar.BarModule`）；
* 远程配置：设置页写 `SharedPreferences("config")`，输入法进程用
  `XposedModule.getRemotePreferences("config")` 读，两条路都走 `XposedProvider`，不需要任何权限；
* 工具栏挂载点：`InputMethodService.getWindow().getWindow().getDecorView()`，
  用 `FrameLayout.LayoutParams(gravity = TOP)` 加进去 —— 就是"键盘上方"；
  建 View 时必须用 **DecorView 的 Context**（带主题），直接用 Service 当 Context 会崩；
* 构建：AGP 8.7.3 / Gradle 8.11.1 / JDK 17 / compileSdk 35，全部由 GitHub Actions 提供。
